# Mubarak Restaurant Website

A static visitor-facing website for Mubarak Restaurant, featuring Kerala, South Indian, North Indian, and Arabic cuisine, with restaurant history and visit details.

## Files

- `index.html` - main website page
- `styles.css` - website styling
- `assets/hero-mubarak-restaurant.png` - homepage food hero image

## View Locally

Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 4173
```

Then visit:

```text
http://127.0.0.1:4173/
```

## Deploy On GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Go to repository `Settings` > `Pages`.
4. Set the source to the main branch and root folder.
5. Save and wait for GitHub Pages to publish the site.
